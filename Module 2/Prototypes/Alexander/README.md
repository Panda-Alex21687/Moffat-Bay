# Moffat Bay Marina – UST-01

This folder contains the UST-01 public website work:

1. `index.html` – landing page structure and navigation
2. `about.html` – marina About Us/information page
3. `contact.html` – Contact Us page and public contact information
4. `styles.css` – shared Moffat Bay Marina visual styling
5. `UST-01-testing.md` – public-access and navigation test notes

The public pages do not require login.

The navigation still includes `reservation.html` and `login.html` because those links were present in the submitted landing page. Those pages are expected to be completed by their related user stories.
