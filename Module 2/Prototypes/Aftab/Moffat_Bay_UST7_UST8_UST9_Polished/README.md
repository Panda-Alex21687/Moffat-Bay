# Polished UST-07 / UST-08 / UST-09 Prototype
CSD 460 Module 2 reference prototype for Moffat Bay Marina.

## Start
Open `reservation-summary.html`.

## Stories
- UST-07: Reservation Summary
- UST-08: Reservation Lookup and History
- UST-09: Reservation Cancellation

## Design
Montserrat headings/navigation/buttons; Open Sans body text; deep navy and gold visual system.

## Prototype only
This version uses browser localStorage to simulate reservation state. It does not connect to MySQL or implement final authentication.
